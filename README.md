## Selected work

### [OrderFlow](https://github.com/NithishKumar04/orderflow-platform)

**Event-driven commerce platform · Java 21 · Spring Boot · Kafka · PostgreSQL · Redis · React**

A failure-aware checkout workflow built beyond CRUD. Orders are accepted
transactionally, published through an outbox, processed asynchronously, and
protected against duplicate delivery and partial failure.

| Reliability | Consistency | Operations |
| --- | --- | --- |
| Retry budget, dead-letter handling, idempotent consumers | Atomic inventory reservation, optimistic locking, compensation | Prometheus metrics, correlation IDs, health probes, full-topology CI |
