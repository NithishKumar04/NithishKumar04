### [OrderFlow](https://github.com/NithishKumar04/orderflow-platform) · Event-driven commerce platform

[![CI](https://github.com/NithishKumar04/orderflow-platform/actions/workflows/ci.yml/badge.svg)](https://github.com/NithishKumar04/orderflow-platform/actions/workflows/ci.yml)
[![Java 21](https://img.shields.io/badge/Java-21-ED8B00?style=flat-square&logo=openjdk&logoColor=white)](https://openjdk.org/projects/jdk/21/)
[![Spring Boot](https://img.shields.io/badge/Spring_Boot-3.4-6DB33F?style=flat-square&logo=springboot&logoColor=white)](https://spring.io/projects/spring-boot)
[![Kafka](https://img.shields.io/badge/Kafka-Redpanda-111111?style=flat-square&logo=apachekafka&logoColor=white)](https://kafka.apache.org/)
[![React](https://img.shields.io/badge/React-TypeScript-149ECA?style=flat-square&logo=react&logoColor=white)](https://react.dev/)

A production-style order workflow that goes beyond CRUD: transactional outbox,
at-least-once delivery, idempotent consumers, atomic inventory reservation,
payment compensation, explicit state transitions, metrics, and a full
PostgreSQL/Redis/Redpanda Docker topology.
