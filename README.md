## Featured project

### [OrderFlow — event-driven commerce platform](https://github.com/NithishKumar04/orderflow-platform)

<a href="https://github.com/NithishKumar04/orderflow-platform">
  <img src="./assets/orderflow-showcase.png" alt="OrderFlow storefront and asynchronous order-state timeline" width="100%">
</a>

A full-stack checkout workflow designed for duplicate delivery, concurrency,
and partial failure—not just the happy path.

- **Durable messaging:** transactional outbox, bounded retries, dead-letter
  handling, and idempotent consumers
- **Consistent state:** atomic inventory reservation, optimistic locking, and
  compensation when payment fails
- **Production feedback:** health probes, Prometheus metrics, correlation IDs,
  integration tests, and full-topology CI
